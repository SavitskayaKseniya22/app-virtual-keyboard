# [Virtual keyboard](https://app-virtual-keyboard.netlify.app)

Simple virtual keyboard

## Tech Stack

- Javascript
- Sass
- Eslint
- Prettier
- Vite
- Normalize.css

## How to use

1. Clone the repo

```bash
git clone https://github.com/SavitskayaKseniya22/virtual-keyboard.git
```

2. Change directory

```bash
cd virtual-keyboard
```

3. Install dependencies

```bash
npm install
```

4. Start the dev server

```bash
npm start
```

For a production build, run `npm run build`. To serve the build locally, run `npm run preview`.
